# SYSTEM ARCHITECTURE & COMPONENT TAXONOMY
Target Application: Cohort PCCOE Clone (Student Social & Community Platform)
Frontend Framework: React 19 + Vite + Tailwind CSS (Lucide React Icons)

================================================================================
1. ARCHITECTURAL OVERVIEW
================================================================================

+-------------------------------------------------------------------------------+
|                                CLIENT BROWSER                                 |
+-------------------------------------------------------------------------------+
                                      |
         +----------------------------+----------------------------+
         |                                                         |
+--------------------+                                    +--------------------+

|  - Navbar & Header |                                    |    - Auth Context  |
|  - Hero Section    |                                    |    - Active Tab    |
|  - Community Ticker|                                    |    - Feed Store    |
|  - Footer / Modals |                                    |    - Filter Store  |
+--------------------+                                    +--------------------+
         |                                                         |
         +----------------------------+----------------------------+
                                      |
              +-----------------------+-----------------------+
              |                                               |
+--------------------------------+             +-------------------------------+
|     FEATURE MODULE ROUTER      |             |         MOCK SERVICES         |
|  1. [Home Feed Module]         |             |  - MockAuthService (Google)   |
|     * Post creation / reaction |             |  - MockFeedService (Posts)    |
|     * Category tags & sorting  |             |  - MockCommunityService (Clubs|
